# Диаграмма интеграции при записи на прием

Сценарий: Пациент записывается на прием через мобильное приложение. Данные синхронизируются с медицинской системой (МИС) и системой бухгалтерии (1С).

```mermaid
sequenceDiagram
    autonumber
    actor P as Пациент (Приложение)
    participant B as Бэкенд приложения
    participant M as МИС (Медкарта)
    participant C as 1С (Биллинг)

    P-»B: POST /appointments (Запись)
    B-»M: Создать талон к врачу
    M--»B: Талон создан (ID 123)
    B-»C: Забронировать счет пациента
    C--»B: Счет создан
    B--»P: Ответ 201 (Успешно)
    B-»P: Push-уведомление (Напоминание)
```
