# analyst-portfolio
Портфолио аналитика

Доброго времени суток! Меня зовут Побежимова София. Я начинающий аналитик (системный/бизнес анализ).

Здесь собраны мои учебные кейсы, которые показывают навыки:
- описание требований (User Stories, Use Cases);
- проектирование API (REST, JSON);
- моделирование данных (ERD);
- построение диаграмм (BPMN, UML, Sequence);
- описание интеграций и NFR.

Я умею переводить потребности бизнеса в технические требования. В моих кейсах есть как экономическое обоснование проектов (ROI, NPV, KPI), так и техническое проектирование (API, ERD, интеграции)».
