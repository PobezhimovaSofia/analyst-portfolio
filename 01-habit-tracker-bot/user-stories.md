# User Stories

## Основные сценарии

| ID | Как | Хочу | Чтобы |
|----|-----|------|-------|
| US-01 | пользователь | создать привычку | отслеживать её выполнение |
| US-02 | пользователь | задать время напоминания | не забывать о привычке |
| US-03 | пользователь | отметить привычку выполненной | видеть прогресс |
| US-04 | пользователь | посмотреть статистику за неделю | понимать результат |
| US-05 | пользователь | удалить привычку | убрать ненужное |
| US-06 | пользователь | изменить время напоминания | подстроить под расписание |
| US-07 | пользователь | отключить напоминания | не получать уведомления в отпуске |

## Критерии приёмки (пример для US-01)

**Дано:** пользователь в главном меню бота.
**Когда:** он выбирает «Создать привычку» и вводит название.
**Тогда:** привычка сохраняется и появляется в списке.

## Ограничения
- Одна привычка — одно напоминание в день.
- Название привычки — до 100 символов.
- Статистика хранится за последние 30 дней.
