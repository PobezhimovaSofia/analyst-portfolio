# Нефункциональные требования

## Производительность
- Ответ бота на команду — не более 2 секунд.
- Обработка напоминаний — раз в минуту, задержка до 60 секунд.

## Доступность
- Доступность сервиса — 99% в месяц.
- При недоступности VK API — повторная отправка 3 раза с интервалом 5 сек.

## Безопасность
- Хранение только vk_id, без персональных данных.
- Авторизация через VK OAuth.
- Ограничение: не более 50 привычек на пользователя.

## Масштабируемость
- До 10 000 активных пользователей без изменения архитектуры.

## Логирование
- Логировать все ошибки интеграции с VK API.
- Хранить логи 30 дней.
