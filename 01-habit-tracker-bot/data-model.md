# Модель данных

## Сущности

### Пользователь (User)
| Поле | Тип | Описание | Ограничение |
|------|-----|----------|-------------|
| id | int | Внутренний ID | PK, автоинкремент |
| vk_id | bigint | ID в VK | Уникальный, NOT NULL |
| first_name | varchar(50) | Имя | |
| created_at | timestamp | Дата регистрации | |

### Привычка (Habit)
| Поле | Тип | Описание | Ограничение |
|------|-----|----------|-------------|
| id | int | ID привычки | PK |
| user_id | int | Ссылка на пользователя | FK → User.id |
| name | varchar(100) | Название | NOT NULL |
| reminder_time | time | Время напоминания | |
| is_active | boolean | Активна ли | По умолчанию true |
| created_at | timestamp | Дата создания | |

### Отметка (Checkin)
| Поле | Тип | Описание | Ограничение |
|------|-----|----------|-------------|
| id | int | ID отметки | PK |
| habit_id | int | Ссылка на привычку | FK → Habit.id |
| checkin_date | date | Дата выполнения | |
| created_at | timestamp | Когда отмечено | |

## Связи
- Пользователь 1 → N Привычки (Один пользователь может иметь много привычек)
- Привычка 1 → N Отметки (Одна привычка может иметь много отметок)
